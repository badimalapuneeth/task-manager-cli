# Learning Notes – Python CLI Task Manager

## 1. Python Fundamentals

- Learned how to create and use variables.
- Practiced Python data types such as strings, integers, lists, and dictionaries.
- Learned how to access list elements and dictionary values.

## 2. Functions

- Learned how to define functions using `def`.
- Practiced calling functions.
- Used `return` to exit a function.
- Used `global` to update the task ID variable.

## 3. Control Flow

- Used `if`, `elif`, and `else` for decision-making.
- Used `while True` to repeat the menu.
- Used `break` to exit the loop.
- Used `for` loops to display tasks.

## 4. Task Management

- Stored tasks in a list of dictionaries.
- Generated unique numeric task IDs.
- Assigned the default status `pending`.
- Used `append()` to add tasks.
- Used `.strip()` to remove surrounding whitespace and validate task titles.

## 5. Error Handling

- Used `try` and `except` to handle keyboard interruption.
- Handled invalid menu choices without crashing.
- Displayed an error message for empty task titles.

## 6. Project Tools

- Used Python 3.12.
- Initialized the project using uv.
- Learned about `pyproject.toml` and `uv.lock`.
- Used Git to track project changes and create commits.

## 7. Key Takeaways

Built a Python command-line task manager and practiced Python fundamentals, project setup, input validation, error handling, and Git version control.
